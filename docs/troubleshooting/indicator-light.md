# Indicator light

The illuminated logo on the front of the device shows what it is doing. The everyday patterns come first; the last three only appear while you hold the reset button.

| Pattern | Meaning |
| --- | --- |
| **Steady, dimmed glow** that never goes dark | Normal operation. The device is running, whether or not it currently has a connection. |
| **Steady glow with a brief dip** once a second | Taking a reading. Lasts about 30 seconds, roughly every 4 minutes. |
| **Bright for 3 seconds, dark for 1** | Setup mode. The device has no Wi-Fi settings and is waiting for the app. See [Connect the device to the app](../setting-up/connect-to-app.mdx). |
| **Short flash once a second**, for 10 seconds | The Wi-Fi password was not accepted, or the network was not found. Try again from the app. |
| **Rapid flicker** | Wi-Fi settings received. The device is joining your network. |
| **Very fast flashing** while you hold the reset button | You have held the button for 3 seconds. Let go now to reset the Wi-Fi settings. See [Reset the device](./reset-the-device.md). |
| **Long on, short off** while you keep holding | You have held the button for 10 seconds. Letting go now rolls the software back to the previous version. |
| **Short blink, long pause** while you keep holding | 10 seconds held, but no previous software version is available. Letting go does nothing. |

The light does not show whether the device is connected to Wi-Fi or to the cloud. If the app shows no recent readings while the logo glows steadily, see [Common problems](./common-problems.md).
