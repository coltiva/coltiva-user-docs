# Using the app

Get the app from [Google Play](https://play.google.com/store/apps/details?id=eu.coltiva.coltivaapp).

## Groups and grow systems

Everyone who logs in belongs to a **group**, the shared account for a grow room. Each Coltiva device in it appears as a **grow system**. Tap a grow system to see its readings.

To share access, open the **⋮** menu on the main screen and choose **Members**. Invitations show up in the other person's app when they log in. All members can run pumps and change automation.

## Readings

The grow system screen shows the latest value of every sensor, when it was last updated, and a chart of the past week. The device takes a reading about every 4 minutes. Pull down to refresh.

## Alarms

Coltiva can send a push notification when a value leaves the range you find acceptable. Tap the gear icon on the grow system screen, then **Notification thresholds**. For each sensor, set the range, tick whether to alert above it, below it, or both, and tap **Apply**.

- An alarm for the same sensor is repeated at most every 12 hours.
- Alarms go to the phone you logged in on most recently.

## Pumps

**Pumps** on the grow system screen lists your pumps. Open one to name it, calibrate it or run it by hand. See [Running a pump by hand](./pumps.mdx#running-a-pump-by-hand).

## Automation

**Automation** on the grow system screen is where you set up pH Control, EC Control and Water Level. See [How automation works](./automation/how-it-works.md).

## Your account

**App & account info** in the **⋮** menu shows your app version, which support may ask for. **Delete account** in the same menu removes your account.
